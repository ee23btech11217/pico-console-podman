# Datasheet-derived implementation (RP2350)

Source: `RP-008373-DS-3-rp2350-datasheet.pdf` (workspace root). Text: `python3 -I tools/ds_text.py RP-008373-DS-3-rp2350-datasheet.pdf > ds.txt`, then grep (`page|text` lines; the PDF page index is one higher than the printed page number).

Rule: every firmware choice about power, clocks, pads, sleep or temperature is listed here with the datasheet section it comes from, the code that implements it, and its verification status. Update this file in the same change as the code.

Status: **HW** = verified on the board (log and/or user), **built** = compiled only, **planned** = not implemented.
